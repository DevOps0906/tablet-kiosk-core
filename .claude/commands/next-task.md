---
description: 다음 대기 작업을 찾아 계획을 세우고 진행
---
1. `tasks/README.md`의 작업 표에서 상태가 `대기`이고 선행 작업이 모두 `완료`인 가장 앞 번호 작업을 고른다. $ARGUMENTS 에 작업 번호가 있으면 그 작업을 고른다.
2. 해당 `tasks/task-XXX.md`와 "참고 문서"에 적힌 문서를 모두 읽는다. 업종 설계 저장소 문서가 있으면 `--add-dir`로 열려 있는지 확인하고, 없으면 사용자에게 열어 달라고 말한다.
3. 구현 계획(바꿀 파일, 순서, 확인 방법)을 짧게 정리해 사용자에게 보여 주고 승인을 받는다.
4. 승인 후 진행한다. "안 할 것"은 건드리지 않는다.
5. 완료 조건을 하나씩 확인하고 결과를 표로 보고한다.
6. `tasks/README.md` 상태를 `완료`로 바꾸고, 루트 CLAUDE.md 6장 형식으로 커밋한다.
