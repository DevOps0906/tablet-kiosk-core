# nextjs-expert — pitfalls (리뷰 1순위 체크리스트)

| # | 함정 | 증상 · 위험 | 확인 방법 |
|---|---|---|---|
| 1 | 비밀을 `NEXT_PUBLIC_*`로 선언 | 키가 브라우저 번들에 노출 | `.env*`, Grep `NEXT_PUBLIC_` |
| 2 | service role 키를 대시보드에서 사용 | RLS 우회 · 다른 매장 데이터 노출 | Grep `service_role`, 키 변수명 |
| 3 | 클라이언트 상태만으로 라우트 보호 | 직접 URL 접근 시 우회 | 보호 라우트의 서버 측 검사 |
| 4 | 서버 컴포넌트에서 `window` · `localStorage` | 빌드 · 런타임 오류 | 사용 위치 |
| 5 | 캐싱 기본값을 모르고 갱신 기대 | 쿠폰 사용 현황이 오래된 값 | 페칭 옵션 · 재검증 (버전별 기본값 확인) |
| 6 | `"use client"` 남발 | 번들 증가 | 클라이언트 경계가 말단인지 |
| 7 | 에러 · 로딩 · 빈 상태 누락 | 빈 화면 · 무한 로딩 | 라우트별 `loading`/`error` |
| 8 | 응답을 `any`로 소비 | 계약 변경 시 조용히 깨짐 | 타입 · 검증 유무 |
| 9 | 서버 액션 입력 미검증 · 매장 소유 미확인 | 다른 매장 쿠폰 발행 | 액션 시작부 |
| 10 | 금액을 `Number` 실수 연산 | 할인 계산 오차 | 정수 연산 · 서버 계산 값 사용 |
| 11 | 반응형 구간 · 글자 크기 하드코딩 | 3구간 기준과 어긋남 | CSS 변수 사용 여부 |
