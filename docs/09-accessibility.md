# 09 접근성 — 배리어프리 키오스크 대응

## 1. 법적 배경 (요약, 판매 전 최신 공고 재확인)

- 장애인차별금지법 개정에 따라 키오스크를 둔 시설은 **2026년 1월 28일까지** 접근성 보장 조치를 마쳐야 합니다. 기존 설치 기기도 포함됩니다.
- **일반 매장**: 과학기술정보통신부 접근성 검증 기준을 충족한 키오스크 + 키오스크 위치를 알려주는 음성 안내 장치.
- **소상공인 매장** (바닥면적 50㎡ 미만 소규모 근린생활시설, 소상공인기본법상 소상공인, 테이블오더형 소형 제품 설치 매장 등): 아래 중 하나 선택
  1. 검증 기준을 충족한 키오스크 + 음성 안내 장치
  2. 기존 키오스크와 호환되는 보조기기 또는 보조 소프트웨어
  3. 직원 도움을 줄 보조 인력 배치 + 호출벨
- 위반이 차별로 인정되면 최대 3천만 원 이하 과태료가 부과될 수 있습니다.

출처: 토스플레이스 「배리어프리 키오스크 의무화, 사장님은 어떤 준비가 필요할까요?」, 뉴시스 2026-01-27 보도.

## 2. 제품 대응 단계

| 단계 | 대상 | 제공 기능 |
|---|---|---|
| MVP | 소상공인 매장 (갤럭시탭형 주 고객) | **직원 호출 버튼** (모든 손님 화면 하단), 호출 시 카운터 알림(소리 + 사장님 기기 / 프린터 호출표) → 선택지 3번 대응 지원 |
| 확장 | 소상공인 매장 | **접근성 모드**: 큰 글씨(1.4배), 고대비 테마, 화면 아래쪽에 주요 버튼 모으기(낮은 자세 · 휠체어 이용자), 단계마다 음성 안내(TTS) |
| 하드웨어 판매 | 일반 매장 (스탠드형) | 과기정통부 접근성 검증 기준 충족 검토, 음성 안내 장치 · 이어폰 단자 · 물리 키패드 등 하드웨어 공급사와 협의 |

## 3. 화면 설계 규칙 (지금부터 지킬 것)

- 모든 버튼 · 아이콘에 화면 낭독용 이름(Semantics label)을 붙입니다.
- 색만으로 상태를 구분하지 않습니다 (선택 상태는 색 + 테두리 + 체크 표시).
- 본문 글자 대비는 WCAG AA(4.5:1) 이상. 테마 토큰의 `primary`는 흰 글자와 AA를 만족하도록 정했습니다 (식당 `#007A64` 등).
- 시간 제한(무입력 초기화)은 연장 가능해야 합니다 ("시간을 더 드릴까요?" 안내 후 초기화).
- 결제 중에는 무입력 초기화를 하지 않습니다 (`docs/04`).

## 4. 영업 포인트

개인 매장 사장님에게 "이 키오스크는 직원 호출 기능으로 소상공인 접근성 기준 대응을 돕는다"는 점을 판매 자료에 넣습니다. 단, 법적 충족 여부는 매장 상황에 따라 다르므로 "대응 지원"으로 표현하고 보증 표현은 쓰지 않습니다.
