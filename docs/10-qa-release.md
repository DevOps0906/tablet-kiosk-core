# 10 테스트 · 출시

## 1. 테스트 층

| 층 | 도구 | 범위 | 실행 위치 |
|---|---|---|---|
| 단위 | `flutter test` | 금액 계산, N등분 나머지, 쿠폰 할인, 시리얼 정규화, ESC/POS 바이트, 상태 전이 | 윈도우 |
| 위젯 | `flutter test` | 공통 컴포넌트, 화면별 상태(빈 장바구니, 품절, 오류) | 윈도우 |
| 통합 | `integration_test` + 가짜 기기 | 시작 → 결제 → 출력 전체 흐름 (업종별) | 윈도우 / 에뮬레이터 |
| DB | `supabase test db` (pgTAP) | RLS: 다른 매장 데이터 차단, 함수 동작 | 로컬 Supabase |
| 대시보드 | Vitest + Playwright | 쿠폰 발행 폼, 반응형 3구간 레이아웃 | 크롬 |
| 실기 | 수동 체크리스트 (아래) | 카드 · 프린터 · 잠금 | 갤럭시탭 |

## 2. 업종 공통 필수 시나리오

- [ ] 매장 선택 → 메뉴 상단 탭 `매장` 선택 상태 → 주문서에 `매장` 크게 인쇄
- [ ] 포장 선택 → 같은 방식으로 `포장`
- [ ] 전체결제 승인 → 주문서 · 영수증 출력 → 완료 → 시작 화면 복귀
- [ ] 카드 거절 → 다시 결제 → 승인
- [ ] 더치페이 N등분 3명, 나머지 원 처리 확인
- [ ] 더치페이 중 2번째 결제자 거절 → 2번째만 재시도
- [ ] 승인 직후 인터넷 끊김 → 임시 번호 출력 → 복구 후 동기화
- [ ] 프린터 꺼짐 → 출력 대기열 → 사장님 PIN으로 재출력
- [ ] 쿠폰 시리얼 입력 / 바코드 스캔 → 할인 반영 → 결제 완료 후 사용 처리 → 같은 쿠폰 재사용 거부
- [ ] 무입력 초기화 (결제 중에는 안 됨)
- [ ] 직원 호출 버튼 동작
- [ ] 키오스크 잠금 상태에서 홈 · 최근 앱 버튼 막힘, PIN으로만 해제
- [ ] 재부팅 후 앱 자동 실행 + 잠금

업종 전용 시나리오는 각 설계 저장소 `specs/`.

## 3. 실기 체크리스트 (시범 매장 투입 전)

- [ ] 시범 매장 VAN 단말로 실제 1,000원 결제 → 취소
- [ ] 시범 매장 프린터 기종으로 한글 · 2배 크기 · 자르기 확인
- [ ] 8시간 연속 켜 두기 (화면 꺼짐 · 메모리 증가 · 발열 확인)
- [ ] 와이파이 끊었다 연결 반복 10회
- [ ] 하루 100건 주문 시뮬레이션 후 서버 · 로컬 주문 수 일치
