# task-014 사장님 세팅 5단계

## 할 것

- [ ] 1 사장님 시작(휴대폰 번호 인증 로그인 · 기존 계정이면 추가 기기 연결)
- [ ] 2 매장 정보(가게 이름 · **업종 선택** · 로고 · 대표 사진 · 주문 방식 · 손님 호출 방식, 시작 화면 미리보기)
- [ ] 3 메뉴 등록(업종 `preset` 기본값, 사진 · 가격 · 품절)
- [ ] 4 결제 단말 · 프린터 연결(테스트 결제 · 테스트 출력)
- [ ] 5 키오스크 모드(무입력 시간, PIN 설정, 업종 `setupExtras`)
- [ ] `device-register` Edge Function
- [ ] 사장님 PIN 화면: 출력 대기열 · 재출력 · 직원 호출 기록 · 세팅으로
